# React Native Template

Tạo project bằng template này

```shell
npx @react-native-community/cli init Someapp --template @pnthach95/react-native-template --skip-install
```

[Lệnh khác:](https://github.com/react-native-community/cli/blob/main/docs/commands.md#init)
- `--directory <string>` để đổi tên thư mục project
- `--title <string>` để đổi tên app
- `--skip-install` để bỏ qua bước cài đặt dependency
- `--skip-git-init true` để bỏ qua tạo git
- `--install-pods false` để bỏ qua bước cài pod
- `--verbose` để debug
